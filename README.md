# Mineria_Segundo_Proyecto_PowerBI

Proyecto 2 Minería de Datos, dashboard de KPIs en Power BI sobre el DW de Invacom Inc S.A.

## Cómo correrlo

1. Clonar en `C:\Proyecto` (el `.pbix` lee los CSV de ahí):
   ```
   git clone https://github.com/JohnArayaE/Mineria_Segundo_Proyecto_PowerBI.git C:\Proyecto
   ```
2. Abrir `Invacom_Dashboard.pbix` → **Actualizar**.
